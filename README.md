# Замер скорости интернета

Консольный скрипт на Python: делает N (по умолчанию 10) **последовательных** запросов к адресу, каждый раз дожидается полного ответа, считает среднее время запроса, общий объём скачанных данных и печатает скорость скачивания.

Только стандартная библиотека, без зависимостей.

## Требования

Python 3.10+

## Запуск

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Параметры:

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `url` | адрес, к которому стучаться (http/https) | — |
| `-n`, `--count` | количество запросов | 10 |
| `-t`, `--timeout` | таймаут одного запроса, сек | 30 |

Пример вывода:

```
# 1:   10.49 MB    2309.4 ms     36.32 Mbit/s
...
Итого
  Успешных запросов:     10 из 10
  Среднее время запроса: 2093.7 ms
  Скачано всего:         104.86 MB (104857600 B)
  Скорость скачивания:   40.07 Mbit/s (5.01 MB/s)
```

## Единицы измерения

- **Скорость — Mbit/s (мегабиты в секунду, 1 Mbit = 1 000 000 бит)**: в этих единицах скорость указывают провайдеры и speedtest-сервисы. В скобках дублируется в **MB/s** (мегабайты в секунду, 1 MB = 1 000 000 байт).
- **Объём — MB (десятичные, 1 MB = 1 000 000 байт)**, в скобках — точное число байт.
- **Время — миллисекунды (ms)**.

## Как считается

- Время запроса — от отправки запроса до получения последнего байта тела ответа (включает DNS, установку соединения, TLS и скачивание).
- Объём — фактически прочитанные байты тела ответа (заголовки не учитываются).
- Итоговая скорость = общий объём / суммарное время всех успешных запросов.
- Если часть запросов упала (таймаут, ошибка сети), они пропускаются, статистика считается по успешным; код выхода `2`. Если не прошёл ни один — код `1`.

## Тесты

```bash
python -m unittest -v
```

Тесты поднимают локальный HTTP-сервер и проверяют, что тело читается целиком и итоги считаются верно.
